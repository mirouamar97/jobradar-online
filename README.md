# JobRadar DZ — منصة ورادار التوظيف والفرص الذكية بالجزائر 🇩🇿

منصة إلكترونية حديثة وتفاعلية لرصد أحدث فرص العمل والوظائف المؤقتة بالجزائر العاصمة مع ربط مباشر بمحطات الميترو والترامواي ومولد لرسائل التقديم الفورية عبر واتساب والإيميل.

## 🌐 الرابط المنشور المباشر على الإنترنت:
**[https://mirouamar97.github.io/jobradar-online/](https://mirouamar97.github.io/jobradar-online/)**

### ✨ أبرز الميزات:
1. **رادار التوظيف اللحظي**: تصفية مئات عروض العمل الحقيقية بالجزائر العاصمة.
2. **شبكة الميترو والترامواي**: فلترة فورية للوظائف القريبة من محطات باب الزوار، قصر المعارض SAFEX، تافورة، رويسو، أول ماي، والحراش.
3. **مركز العمل المؤقت (Gig Hub)**: صالونات ومعارض قصر المعارض، عروض الأجر اليومي، التوصيل، والفرص الطلابية.
4. **توليد رسائل التقديم الذكية**: توليد فوري لرسائل WhatsApp فرنسية وعربية مع روابط مراسلة مباشرة `wa.me` ورسائل بريد رسمية.
5. **نظام التحفيز والإنجازات (Gamification)**: مستويات، نقاط XP، وسلاسل نشاط يومية 🔥.
6. **بوت تيليغرام التفاعلي**: ربط مباشر مع بوت تيليغرام `@searchamarbot`.
7. **إضافة عروض جديدة**: إمكانية نشر عروض عمل جديدة من قبل أصحاب العمل مباشرة على المنصة.

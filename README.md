# JobRadar DZ — منصة ورادار التوظيف والفرص الذكية بالجزائر 🇩🇿

منصة إلكترونية حديثة وتفاعلية لرصد أحدث فرص العمل والوظائف المؤقتة بالجزائر العاصمة مع ربط مباشر بمحطات الميترو والترامواي وميزة **المراسلة التلقائية لفرص الأنيماتور والمعارض**.

### ✨ أبرز الميزات:
1. **🎪 مركز المراسلة التلقائية لفرص الأنيماتور والمعارض (Animation Auto-Messenger)**:
   - رصد آلي لكافة عروض صالونات ومعارض SAFEX والأنيماسيون.
   - ميزة **المراسلة التسلسلية الآلية (Auto-Send Sequence)** لفتح محادثات WhatsApp مباشرة لجميع أصحاب العروض بنص مجهز واحترافي بنقرة واحدة دون الحاجة للكتابة.
   - استوديو مخصص لتعديل نص التقديم (SAFEX، مبيعات، فعاليات عامة).
2. **رادار التوظيف اللحظي**: تصفية مئات عروض العمل الحقيقية بالجزائر العاصمة.
3. **شبكة الميترو والترامواي**: فلترة فورية للوظائف القريبة من محطات باب الزوار، قصر المعارض SAFEX، تافورة، رويسو، أول ماي، والحراش.
4. **مركز العمل المؤقت (Gig Hub)**: صالونات ومعارض قصر المعارض، عروض الأجر اليومي، التوصيل، والفرص الطلابية.
5. **نظام التحفيز والإنجازات (Gamification)**: مستويات، نقاط XP (+25 XP عند مراسلة عروض الأنيماسيون)، وسلاسل نشاط يومية 🔥.
6. **أدوات التشغيل المحلية**: ملف `Auto_Message_Animation.bat` للتشغيل المكتبي السريع بنقرة واحدة.

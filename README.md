# JobRadar DZ — منصة ورادار التوظيف والفرص الذكية بالجزائر 🇩🇿

منصة إلكترونية حديثة وتفاعلية لرصد أحدث فرص العمل والوظائف المؤقتة بالجزائر العاصمة.

## 🌐 الرابط المنشور المباشر على الإنترنت:
**[https://mirouamar97.github.io/jobradar-online/](https://mirouamar97.github.io/jobradar-online/)**

---

### ✨ أبرز الميزات:
1. **🎪 مركز المراسلة التلقائية لفرص الأنيماتور والمعارض (Animation Auto-Messenger)**:
   - رصد آلي لكافة عروض صالونات ومعارض SAFEX والأنيماسيون.
   - ميزة **المراسلة التسلسلية الآلية (Auto-Send Sequence)** لفتح محادثات WhatsApp مباشرة لجميع أصحاب العروض بنص مجهز واحترافي بنقرة واحدة دون الحاجة للكتابة.
   - استوديو مخصص لتعديل نص التقديم (SAFEX، مبيعات، فعاليات عامة).
2. **رادار التوظيف اللحظي**: تصفية مئات عروض العمل الحقيقية بالجزائر العاصمة.
3. **مركز العمل المؤقت (Gig Hub)**: صالونات ومعارض قصر المعارض، عروض الأجر اليومي، التوصيل، والفرص الطلابية.
4. **نظام التحفيز والإنجازات (Gamification)**: مستويات، نقاط XP (+25 XP عند مراسلة عروض الأنيماسيون)، وسلاسل نشاط يومية 🔥.
5. **أدوات التشغيل المحلية**: ملف `Auto_Message_Animation.bat` للتشغيل المكتبي السريع بنقرة واحدة.

## الربط مع تطبيق أندرويد (JobRadar DZ v3)

يجمع GitHub Actions (`.github/workflows/collect.yml`) العروض كل ساعة من مصادر عامة فقط (مواقع التوظيف، قنوات تيليغرام العامة، بحث الويب) ويكتب `data/offers.json` و`data/status.json` (حالة كل مصدر بصدق). يعرضها هذا الموقع، ويستوردها التطبيق كمصدر باسم «JobRadar Online» من الرابط:

`https://mirouamar97.github.io/jobradar-online/data/offers.json`

قراءة فقط: لا حسابات ولا كلمات سر ولا إرسال. عروض الفعاليات والأنيماسيون لها الأولوية. فيسبوك وإنستغرام وتيك توك تُقرأ من المتصفح داخل التطبيق فقط ولا تظهر هنا.
